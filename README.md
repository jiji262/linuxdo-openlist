# LINUX DO OpenList

> 聚合收录 [LINUX DO 社区 `#开源推广` 专区](https://linux.do/tag/2234-tag/2234) 下的全部开源项目发布帖，清晰整理项目创建时间、功能介绍与对应的开源仓库地址。

## 核心特性

- **全量归档与结构化整理**：完整拉取并解析 `https://linux.do/tag/2234-tag/2234` 下的全部开源推广话题，提取对应的 GitHub / GitLab / Gitee / Codeberg / HuggingFace / GreasyFork 等开源地址、项目简介、发帖时间、作者与社区互动热度。
- **HAPI.run 灵感视觉设计**：采用高辨识度的新锐触感设计语言（圆润几何字体 `Nunito` + 极客等宽字体 `Space Mono` + 硬朗描边与立体偏移阴影）。
- **明 / 暗双主题自由切换**：
  - **深色主题（Dark Mode）**：深邃极夜蓝底色 + 终端霓虹绿主色；
  - **浅色主题（Light Mode）**：温润暖米纸张底色 + 活力珊瑚橙主色。
- **免登录极速检索体验**：支持快捷键 `/` 或 `⌘K` 全文搜索、8 大技术领域分类、热门标签联动过滤、时间范围与月份趋势筛选、卡片网格 / 紧凑清单双视图切换，以及「手气不错」随机探索弹窗。

## 本地运行与构建

```bash
pnpm install
pnpm dev
pnpm build
```

## 技术栈

- **React 19 + TypeScript + Vite 6**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Vercel** 全球边缘网络部署
